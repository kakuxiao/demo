# Scramble String (スクランブル文字列) 判定アルゴリズム

## 1. ルール説明
文字列をランダムに分割・置換して別の文字列を作り出す「スクランブル文字列（Scramble String）」の生成ルールは、以下の再帰的なプロセスに基づいている。

- **終了条件**: 文字列の長さが 1 の場合、分割を終了する。
- **分割（Split）**: 文字列の長さが 1 より大きい場合、任意のインデックスで 2 つの空ではない部分文字列 $x$ と $y$ に分割する（$s = x + y$）。
- **置換（Swap）**: そのまま維持するか、左右を入れ替えるかをランダムに決定する（$s = x + y$ または $s = y + x$）。
- **再帰適用（Recursion）**: 分割されたそれぞれの部分文字列 $x$ と $y$ に対して、ステップ 1 からの処理を再帰的に繰り返す。

---

## 2. なぜ `s1 = "abcde"` と `s2 = "caebd"` は `false` になるのか？
文字全体の総数（`a, b, c, d, e` が各1個ずつ）は一致しているが、**どの分割位置 `i` で切っても、部分文字列の文字種・文字数（アナグラム関係）の条件を満たせないから**である。

スクランブル文字列のルールでは、文字列を左右に分割したとき、以下のいずれかの条件が**必ず**成立しなければならない：
1. **非交換（そのまま）**：`s1` の左側部分文字列の文字集合 ＝ `s2` の左側部分文字列の文字集合
2. **交換（左右反転）**：`s1` の左側部分文字列の文字集合 ＝ `s2` の右側部分文字列の文字集合

すべての分割位置 `i`（1から4）で検証すると、すべて破綻する：
- **分割位置 `i = 1`**：`s1` 左側 `"a"` vs `s2` 左側 `"c"` / 右側 `"d"` $\rightarrow$ 不一致
- **分割位置 `i = 2`**：`s1` 左側 `"ab"` vs `s2` 左側 `"ca"` / 右側 `"bd"` $\rightarrow$ 不一致
- **分割位置 `i = 3`**：`s1` 左側 `"abc"` vs `s2` 左側 `"cae"` / 右側 `"ebd"` $\rightarrow$ 不一致
- **分割位置 `i = 4`**：`s1` 左側 `"abcd"` vs `s2` 左側 `"caeb"` / 右側 `"aebd"` $\rightarrow$ 不一致

どの深さの分割においても再帰的なツリー構造の枝が成立しないため、最終的に `false` を返す。
